# Packages

## 概要

本ドキュメントでは、プロジェクト全体で共有される共通パッケージ (`packages/`) について説明します。

モノレポ構成を活かし、フロントエンドとバックエンドで共通して使用するコードをパッケージとして切り出すことで、コードの再利用性と保守性を向上させています。

## 共通パッケージ

### @repo/domains

ドメインモデル、DTO (Data Transfer Object)、エンティティを定義する共通パッケージです。

#### 主な役割

- **型安全性の確保**: フロントエンドとバックエンドで同じ型定義を共有
- **バリデーションスキーマ**: Valibot を使った共通のバリデーションロジック
- **ドメインロジック**: ビジネスルールの共通実装

#### ディレクトリ構成

- `dto/`: API リクエスト/レスポンスの型定義
- `entity/`: ドメインエンティティの定義
- `relation/`: エンティティ間のリレーション定義

### @repo/biome-config

Biome の共通設定パッケージです。

#### 主な役割

- **統一されたコード品質**: プロジェクト全体で一貫したリンティング・フォーマットルール
- **設定の一元管理**: 各アプリケーションで個別に設定を記述する必要がない
- **メンテナンス性の向上**: ルールの変更を一箇所で管理

## 使用方法

各パッケージは pnpm ワークスペースを通じて、他のパッケージから参照できます。

```typescript
// フロントエンドまたはバックエンドから共通の型を使用
import type { DocumentDto } from '@repo/domains';

// Biome 設定を継承
import biomeConfig from '@repo/biome-config';
```

`@repo/domains` にて、作成・更新したスキーマを `/apps` (front, main-api) に反映させるにはビルドが必要です。

```bash
cd packages/domains
pnpm build
```
