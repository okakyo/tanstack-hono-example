# 環境構築

---

<details>
<summary> 1. Node.js のインストール</summary>

ローカルマシンに Node.js をインストールします。インストールすべき Node.js のバージョンは [.node-version](../.node-version) を確認してください。
インストール方法はお好きなもので構いませんが、こだわりがない、方法が分からない場合は以下で誘導する方法を推奨します。

### 1-1. anyenv のインストール

Node.js のバージョン管理ツールに nodenv というツールがあります。 さらに nodenv などのバージョン管理ツールを管理するための anyenv というツールがあります。

まず最初に anyenv をインストールします。
anyenv はいくつかインストール方法はありますが、Homebrew を用いてインストールすることをオススメします。

- [anyenv のインストール方法](https://github.com/anyenv/anyenv#1-install-and-configure-anyenv)

以下のコマンドを実行して、インストールしてください。

```zsh
brew install anyenv
```

インストールが完了したら以下のコマンドを実行して、 anyenv のバージョンを確認してください。

```zsh
anyenv -v
```

何かしらのバージョンが表示されればインストール成功です。
インストールした anyenv を正しく認識するために、以下のコマンドを実行して起動しているシェルを再起動してください。

```zsh
exec $SHELL -l
```

シェルの再起動が完了したら以下のコマンドを実行し、 anyenv の初期化をしてください。

```zsh
anyenv install --init
```

### 1-2. nodenv のインストール

Node.js のバージョン管理ツール nodenv をインストールします。
以下のコマンドを実行してください。

```zsh
anyenv install nodenv
```

インストールが完了したら以下のコマンドを実行して、 nodenv のバージョンを確認してください。

```zsh
nodenv -v
```

何かしらのバージョンが表示されればインストール成功です。
インストールした nodenv を正しく認識するために、以下のコマンドを実行して起動しているシェルを再起動してください。

```zsh
exec $SHELL -l
```

### 1-3. Node.js のインストール

Node.js を nodenv を用いてインストールします。インストールすべき Node.js のバージョンは [.node-version](../.node-version) を確認してください。
以下のコマンドを実行してください。（`XX.XX.XX`は確認した Node.js のバージョンに置き換えてください。）

```zsh
nodenv install XX.XX.XX
```

インストールが完了したら、インストールした Node.js を正しく認識するために、以下のコマンドを実行して nodenv をrehashしてください。

```bash
nodenv rehash
```

以下のコマンドを実行することで、現在 nodenv で管理している Node.js のバージョンを確認することができます。
先ほどインストールした Node.js のバージョンが確認できればインストール成功です。

```zsh
nodenv versions
```

使用する Node.js のバージョンを指定するには以下のコマンドを実行すればOKです。
なお、本レポジトリでは [.node-version](../.node-version) を設定しているため、本レポジトリ（ディレクトリ）配下では記載されたバージョンの Node.js がインストールされていれば自動的にそのバージョンが使用されるようになっています。
そのため、以下の指定は不要です。

●ローカルマシン全体で使用する Node.js のバージョンを指定する場合

```zsh
nodenv local XX.XX.XX
```

●ローカルマシンの特定のディレクトリで使用する Node.js のバージョンを指定する場合（実行したディレクトリ配下が適用）

```zsh
nodenv global XX.XX.XX
```

<summary>2. pnpm のインストール</summary>

ローカルマシンに pnpmを npm を用いてインストールします。本レポジトリではパッケージ管理ツールとして pnpmを用いるようにしています。
パッケージの依存関係がおかしくならないよう、 npm や pnpm などの別のパッケージ管理ツールの使用は本レポジトリでは控えるようにお願いします。

インストールすべき pnpmのバージョンは [package.json](./package.json) の`engine`を確認してください。
以下のコマンドを実行してください。（`XX.XX.XX`は確認した pnpmのバージョンに置き換えてください。）

```zsh
npm install -g pnpm@XX.XX.XX
```

以下のコマンドを実行して、 pnpmのバージョンを確認してください。

```zsh
pnpm -v
```

先ほどインストールした pnpmのバージョンが確認できればインストール成功です。

</details>

（既にクローン済みの場合は本手順不要）

ローカルマシンに本レポジトリをクローンします。以下のコマンドを実行してください。

```zsh
git clone https://github.com/FAST-TRADE/uretailV2.git
```

<details>
<summary>4. パッケージのインストール</summary>

本ファイルと同じディレクトリ階層（`uretailV2/frontend`）に移動します。
以下のコマンドを実行してください。

```zsh
cd ./uretailV2/frontend
```

クローンしたレポジトリの`uretailV2/frontend`配下に必要なパッケージをインストールします。`uretailV2/frontend`直下で以下のコマンドを実行してください。

```zsh
pnpm install --frozen-lockfile
```

インストールが完了すると、`uretailV2/frontend`直下に`.node_modules`という名前のディレクトリが生成されています。この中に実行に必要なパッケージが入っています。

</details>

<details>
<summary>5. ローカル環境の起動</summary>

以下のコマンドを実行してください。

```zsh
pnpm dev
```

正常に実行ができたら、以下のような出力がされるはずです。

```zsh
next dev -p 4000
#   ▲ Next.js 14.2.3
#   - Local:        http://localhost:4000
#   - Environments: .env
```

上記の出力とともに、デフォルトのWebブラウザで [http://localhost:4000](http://localhost:4000) が表示されると思います。
なお、こだわりがない場合はWebブラウザは Google Chrome または Safari でのアクセスを推奨します。問題なければ無事に表示されます。お疲れ様でした！

</details>
